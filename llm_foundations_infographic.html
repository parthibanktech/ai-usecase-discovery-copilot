LLM Application Foundations

A progressive 9-step blueprint: From raw API tokens to structured data, LCEL pipelines, and interactive AI web apps.

STEP 01 01_first_llm_call.py
⚡ Raw API & Token Budgets
Call OpenAI-compatible APIs directly. Master roles, request anatomy, and token budgeting (1 token ≈ 0.75 words).
response = client.chat.completions.create( model="deepseek-chat", messages=[user_msg], max_tokens=700 )
STEP 02 02_why_a_framework.py
🧩 Framework Abstraction
Why use LangChain? Isolate vendor-specific HTTP wiring so models can be swapped with a single line change.
llm = ChatDeepSeek(model="deepseek-chat") result = llm.invoke(question) print(result.content)
STEP 03 03_temperature.py
🎛️ The Creativity Dial
Control sampling entropy: 0.0 for deterministic analytics/code vs 0.9 for creative brainstorms.
# 0.0 = Deterministic | 0.9 = Creative low_llm = ChatDeepSeek(temperature=0.0) high_llm = ChatDeepSeek(temperature=0.9)
STEP 04 04_system_and_user_roles.py
🎭 System vs User Roles
Same incident data, two completely different answers: Technical RCA for SREs vs business impact for managers.
messages = [ SystemMessage(content="You are an SRE."), HumanMessage(content=incident_text) ]
STEP 05 05_streaming.py
🌊 Live Token Streaming
Eliminate perceived latency. Stream tokens to the terminal or UI as they are generated instead of blocking.
for piece in llm.stream(prompt): print(piece.content, end="", flush=True)
STEP 06 06_prompt_templates.py
📝 Parametric Templates
Decouple prompt architecture from runtime data. Use {placeholders} to turn one-offs into reusable software features.
template = ChatPromptTemplate.from_messages([ ("system", "Write short customer updates."), ("human", "Customer: {customer}\nIssue: {issue}") ])
STEP 07 07_structured_output.py
🛡️ Structured Outputs (Pydantic)
The enterprise game-changer: Replace unpredictable text paragraphs with validated, strongly-typed Python objects.
class Brief(BaseModel): score: int = Field(description="1 to 10") steps: list[str] structured = llm.with_structured_output(Brief)
STEP 08 08_chain_lcel.py
⛓️ LCEL Pipelines (The Pipe)
The Unix philosophy in Python. Pipe components declaratively: Data in ➔ Model call ➔ Validated clean output.
# Prompt ➔ Model ➔ Clean Output Parser chain = prompt | llm | StrOutputParser() result = chain.invoke({"use_case": problem})
STEP 09 09_capstone_use_case_app.py
🚀 Full-Stack Capstone App
Everything united into a live Gradio web app: dynamic temperature toggle, Pydantic roadmap plans, and interactive UI.
with gr.Blocks() as demo: inputs = [domain, problem, creativity] btn.click(discover, inputs, output) demo.launch()
